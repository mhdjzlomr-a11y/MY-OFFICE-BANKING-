# ഓഫീസ് ഫിനാൻസ് | Office Finance Web & Android Mobile App

ഓഫീസിലെ എല്ലാവിധ വരവ്-ചിലവ് കണക്കുകൾ, കാറ്റഗറി അടിസ്ഥാനമാക്കിയുള്ള റിപ്പോർട്ടുകൾ, എക്സൽ & പ്രിന്റബിൾ PDF സ്റ്റേറ്റ്‌മെന്റുകൾ, വൗച്ചറുകൾ, ബാക്കപ്പ് തുടങ്ങിയ എല്ലാ ഫീച്ചറുകളും അടങ്ങിയ അത്യാധുനിക **Progressive Web Application (PWA)**.

---

## 📱 ആൻഡ്രോയിഡ് മൊബൈലിൽ ആപ്പായി എങ്ങനെ ഇൻസ്റ്റാൾ ചെയ്യാം? (How to Install on Android)

1. ഈ ഫയലുകൾ ഒരു വെബ് സെർവറിലോ (GitHub Pages, Netlify, Vercel, Firebase അല്ലെങ്കിൽ ലോക്കൽ വൈഫൈ വഴി) ഹോസ്റ്റ് ചെയ്യുക അല്ലെങ്കിൽ ഫോണിലെ Chrome ബ്രൗസറിൽ `index.html` തുറക്കുക.
2. ഫോണിലെ ഗൂഗിൾ ക്രോമിൽ (Google Chrome) തുറക്കുമ്പോൾ മുകളിൽ **"ആപ്പ് ഇൻസ്റ്റാൾ ചെയ്യുക" (Install App)** ബട്ടൺ കാണാം (അല്ലെങ്കിൽ ബ്രൗസറിന്റെ മുകളിലെ 3 ഡോട്ടുകൾ ക്ലിക്ക് ചെയ്ത് **"Install app"** / **"Add to Home screen"** തിരഞ്ഞെടുക്കുക).
3. നിങ്ങളുടെ ആൻഡ്രോയിഡ് ഫോണിന്റെ ഹോം സ്ക്രീനിൽ മറ്റ് ആപ്പുകളെപ്പോലെ തന്നെ ഓഫീസ് ഫിനാൻസ് ആപ്പ് ഐക്കൺ വരുന്നതാണ്.
4. ആപ്പ് തുറക്കുമ്പോൾ ഫുൾ സ്ക്രീനിൽ, ഇന്റർനെറ്റ് ഇല്ലാതെയും (100% Offline) അതിവേഗത്തിൽ പ്രവർത്തിക്കും!

---

## 💻 കമ്പ്യൂട്ടറിൽ എങ്ങനെ തുറക്കാം? (How to Run on PC)
- ഫോൾഡറിലെ `start-app.bat` എന്ന ഫയലിൽ ഡബിൾ ക്ലിക്ക് ചെയ്യുക (അല്ലെങ്കിൽ `index.html` ഫയൽ Chrome / Edge ബ്രൗസറിൽ തുറക്കുക).

## 🌟 പ്രധാന സവിശേഷതകൾ (Key Features)

- **വരവ്-ചിലവ് രേഖപ്പെടുത്തൽ (Income & Expense Ledger)**:
  - ഓഫീസ് വാടക, ശമ്പളം, കറന്റ്, ഇന്റർനെറ്റ്, ചായ/ലഘുഭക്ഷണം, സ്റ്റേഷനറി, മെയിന്റനൻസ്, ക്ലയന്റ് പേയ്‌മെന്റ് തുടങ്ങി 25-ലധികം കാറ്റഗറികൾ.
  - തുക, തീയതി, വ്യക്തി/സ്ഥാപനം, ബിൽ നമ്പർ, കുറിപ്പുകൾ.
  - ഫോൺ ക്യാമറ വഴിയോ ഗാലറി വഴിയോ ബിൽ/രസീത് ഫോട്ടോ അറ്റാച്ച് ചെയ്യാനുള്ള സൗകര്യം.
- **ഡൈനാമിക് കസ്റ്റം കാറ്റഗറികൾ (Dynamic Custom Categories)**:
  - ആവശ്യാനുസരണം ഏത് സമയത്തും പേരും നിറവും നൽകി പുതിയ വരവ് അല്ലെങ്കിൽ ചിലവ് കാറ്റഗറികൾ സ്വയം ആഡ് ചെയ്യാം.
- **വിഷ്വൽ ഡാഷ്‌ബോർഡ് (Analytics Dashboard)**:
  - ആകെ മിച്ചം, ആകെ വരവ്, ആകെ ചിലവ്, ഈ മാസത്തെ കണക്ക്.
  - പ്രതിമാസ ട്രെൻഡ് ചാർട്ടും കാറ്റഗറി ഡോനട്ട് ചാർട്ടും (Chart.js).
- **ഔദ്യോഗിക റിപ്പോർട്ടുകളും ഡൗൺലോഡുകളും (Reports & Exports)**:
  - ഓഫീസിന്റെ ലോഗോയും പേരും അടങ്ങിയ **പ്രൊഫഷണൽ ഫിനാൻഷ്യൽ സ്റ്റേറ്റ്‌മെന്റ് PDF ഡൗൺലോഡ്**.
  - ഓരോ ഇടപാടിനും നൽകാവുന്ന **സിംഗിൾ വൗച്ചർ / രസീത് PDF**.
  - സി.എ / അക്കൗണ്ടിംഗ് ആവശ്യങ്ങൾക്കായി **എക്സൽ (Excel / CSV) ഡൗൺലോഡ്**.
- **മലയാളം & ഇംഗ്ലീഷ് ദ്വിഭാഷാ സൗകര്യം (Bilingual)**:
  - മുകളിലെ ഗ്ലോബ് ബട്ടൺ വഴി ഒറ്റ ക്ലിക്കിൽ മലയാളത്തിലേക്കും ഇംഗ്ലീഷിലേക്കും മാറ്റാം.
- **ഡാറ്റാ സുരക്ഷയും ബാക്കപ്പും (Data Security & Backup)**:
  - 4-അക്ക സെക്യൂരിറ്റി PIN ലോക്ക്.
  - 100% ഓഫ്‌ലൈൻ സുരക്ഷിത സ്റ്റോറേജ് (IndexedDB).
  - ഒരൊറ്റ ക്ലിക്കിൽ JSON ബാക്കപ്പ് ഡൗൺലോഡ് ചെയ്യാനും റീസ്റ്റോർ ചെയ്യാനും ഉള്ള സൗകര്യം.
